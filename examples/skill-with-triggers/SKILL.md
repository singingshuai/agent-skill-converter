# Trigger Skill

A skill with complex trigger conditions.

## When to Use

Use when user asks about database optimization, query performance, or indexing strategies. Also use when user mentions slow queries or database bottlenecks.

## Workflow

1. Analyze query structure
2. Identify bottlenecks
3. Suggest optimizations
4. Provide implementation examples

## Constraints

- Do not modify production databases
- Always test changes in staging first
- Back up before any schema changes

## Examples

- Optimize SELECT queries
- Add appropriate indexes
- Rewrite complex joins
