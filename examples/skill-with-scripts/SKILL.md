# Script Skill

A skill with executable scripts.

## When to Use

Use when running automated tests.

## Workflow

1. Install dependencies
2. Run test suite
3. Collect results

## Constraints

- Do not run in production
- Always use virtual environment

## Resources

- scripts/run_tests.sh: Test runner script
- scripts/collect_results.py: Results collector

## Examples

- Run unit tests
- Run integration tests
